## LinkedIn project description

SetCtl is my workout tracking PWA, built around unreliable gym connectivity and a focused mobile training flow. It combines reusable plans, local set logging, exercise reordering and progress review. The engineering case study covers IndexedDB transactions, recoverable synchronization, revision-guarded D1 writes and cross-browser testing. Built with React, TypeScript and Cloudflare, using AI coding assistance.
